PersonalMetrics privacy policy

Last updated: 26 October 2026

PersonalMetrics is a personal tool used only by its developer, with the developer's own Google account.

Data accessed

With read-only access, the app gets sleep, activity and fitness data from the Google Health API.

How data is used and stored

The data is stored only on the developer's own computer, and is used only for a private personal dashboard. It is not sent to any server, sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

PersonalMetrics's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored data can be deleted by removing the app's data files.

Contact

Open an issue at github.com/headcrabned/personalmetrics/issues.
